# 優待クロス取引管理アプリ

株主優待クロス取引の記録・管理・損益計算を行うWebアプリです。

## 概要

| 項目 | 内容 |
|------|------|
| バックエンド | Python / Flask |
| フロントエンド | HTML / CSS / Tailwind CSS |
| データ | Googleスプレッドシート（既存のものをそのまま利用） |
| ホスティング | Vercel（無料） |

GASのWebアプリと同じスプレッドシートに接続しつつ、GASバナーなし・高速なWebアプリとして動作します。

## 機能

- **銘柄登録** — 優待銘柄のマスター情報を登録
- **取引一覧** — ステータス・月・銘柄名で絞り込み表示
- **損益計算** — 決済済み取引の損益サマリー・月別・年別集計
- **設定** — 証券会社一覧・デフォルト値の管理

## ファイル構成

```
├── main.py              Flask アプリ本体・APIルート
├── db.py                Google Sheets API 接続・CRUD処理
├── requirements.txt     依存パッケージ
├── vercel.json          Vercel デプロイ設定
└── templates/
    └── index.html       フロントエンド（シングルページ）
```

## 環境変数（Vercelに設定）

| 変数名 | 内容 |
|--------|------|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | サービスアカウントのJSONファイルの中身 |
| `SPREADSHEET_ID` | スプレッドシートURLの `/d/〇〇〇/` の部分 |
